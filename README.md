# HR Employee Attendance & Absenteeism Analytics Dashboard

## Project Overview

This project focuses on analyzing employee information and attendance records using Microsoft Power BI. The dashboard presents HR-related information, employee distribution, attendance patterns, absenteeism, and late arrivals.

The report is divided into two main sections:

1. HR Employee Overview
2. Employee Attendance & Absenteeism Analysis

## Dashboard Sections

### 1. HR Employee Overview

This section provides an overview of employee information, including:

- Total Employees
- Active and Resigned Employees
- Department-wise Employee Distribution
- City-wise Employee Distribution
- Gender Distribution
- Average Monthly Salary
- Average Performance Rating

### 2. Employee Attendance & Absenteeism Analysis

This section focuses on employee attendance records and absence patterns.

Key metrics include:

- Total Attendance Records: 440
- Attended Records: 324
- Absent Records: 49
- Attendance Rate: 73.64%
- Late Days: 42
- Total Late Minutes: 840
- Average Late Minutes: 20

Additional analysis includes attendance trends, department-wise attendance, employee absenteeism, and late-arrival analysis.
